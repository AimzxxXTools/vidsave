# Website Pencari & Pengunduh Media

Website ini dikembangkan oleh **Kitzxyaping** menggunakan antarmuka modern **DarkGlass** yang responsif untuk perangkat seluler maupun komputer.

## Fitur Utama
- **Pencarian Media**: Mencari konten media berbasis backend serverless.
- **Desain DarkGlass**: Tampilan transparan bergaya kaca gelap yang elegan dan estetis.
- **Sepenuhnya Bahasa Indonesia**: Seluruh teks panduan dan antarmuka disesuaikan dalam bahasa Indonesia.

---

## Cara Deploy ke Vercel

1. Ekstrak file ZIP ini ke komputer Anda.
2. Upload / Push folder ini ke repository GitHub Anda.
3. Buka [Vercel Dashboard](https://vercel.com/dashboard) dan pilih **Add New > Project**.
4. Impor repository GitHub Anda.
5. Klik **Deploy**. Vercel akan otomatis mengenali berkas `vercel.json` dan memproses serverless function serta file statis.
